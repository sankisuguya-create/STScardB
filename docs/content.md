## 課題

### わからない問題（normal）

- 状きょう：算数の じゅぎょう中。黒板の 問題を 見ても、どうやって とけば いいのか わからない。まわりの 子は どんどん ノートに 書いている…
- 3つの姿：ハテナ だいまじん → むずかしそうな プリント → わからない 1問
- つぎに起きそうなこと：あせってくる／どんどん むずかしく見えてくる／まわりが すすんでいく
- 場面カード：「わからない」と言う、となりの人に 聞く、とばして 次へ
- 相手から見ると：となりの子：「聞いてくれたら、すぐ 教えたのに」

### ろうかで ぶつかられた（normal）

- 状きょう：休み時間、ろうかを 歩いていたら、うしろから ドンッと ぶつかられた。かたが いたい。「わざと？」と 思った しゅんかん、むかっと した。
- 3つの姿：ドンッと ぶつかる かいぶつ → わざと ぶつかってきた？ あの子 → よそ見して ぶつかっただけ

## できごと

### わすれものに 気づいた朝

教室について、算数のノートを わすれたことに 気づいた。

- 先生に 正直に言う → 「言いに来てくれて ありがとう」と言われた。
- となりの子に 紙を 一まい もらう（信頼5以上） → 「いいよ」と すぐ 貸してくれた。
- だまっておく → じゅぎょう中、ずっと 気になってしまった。

### 友だちが こまっている

給食のあと、友だちが 牛にゅうを こぼして こまっている。

- 「手つだおうか？」と言う → いっしょに ふいた。「ありがとう」と言われた。
- 先生を よびに行く → 先生が ぞうきんを 持ってきてくれた。
- 見なかったことにする → そのまま 席にもどった。

### 休み時間

チャイムが 鳴った。校庭から 友だちの 声が 聞こえる。

- 友だちと 外で 遊ぶ → 思いきり 走って わらった。気もちが 軽くなった。
- 友だちと おしゃべりする → くだらない 話で もりあがった。少し ほっとした。
- 一人で ぼんやりする → 少しだけ 休めた。

### 図書室で 本を 見つけた

休み時間に 図書室へ 行ったら、気になる 本が 3さつ あった。

- 『気もちの ことば じてん』を 読む → 気もちを 言葉に すると すっきりする、と 書いてあった。
- 『べんきょうの コツ』を 読む → 時間を 決めると 集中できる、と わかった。
- 『友だちと なかよく』を 読む → 「ありがとう」の 言い方が いろいろ のっていた。

### 夕ごはんの 時間

お家の人が「今日は どうだった？」と 聞いてくれた。

- 今日 あったことを 話す → 話したら 気もちが 軽くなった。
- 「ふつう」とだけ 言う → そのまま ごはんを 食べた。

### トラブル：先生に よばれた

さっき 手が 出てしまった ことで、先生に よばれた。相手の子も 来ている。

- 何が あったか 正直に 話して、あやまる → 先生：「話してくれて ありがとう。次は 手が 出る前に、はなれるか 先生を よぼうね」。相手の子とも なかなおりできた。
- 「むこうが 先に やった」と 言う → 先生：「どちらの 話も 聞くね」。でも、自分のしたことは 残ったままだ。
- だまって 下を 向く → 先生が 待ってくれたけど、何も 言えなかった。

### トラブル：クラスの 空気が 悪くなった

大きな声を 出したことで、まわりの 子が びっくりしている。先生が「どうしたの？」と 来てくれた。

- 気もちを 話して、「大きな声を 出して ごめん」と 言う → 先生：「おこった 気もちは 大事。つたえ方を いっしょに 考えよう」
- 「べつに」と 言って はなれる → しばらく だれも 話しかけて こなかった。

### トラブル：うわさが 広がった

言ったことが 広がって、相手の子が ないている。先生が 二人を よんで 話を 聞いてくれる。

- 言ったことを みとめて、あやまる → 先生：「言葉は 消せないけど、あやまる ことは できる。よく 言えたね」
- 「みんなも 言ってた」と 言う → 先生：「みんなの ことじゃなく、自分の ことを 考えよう」

### 先生が 声を かけてくれた

一人で かかえこんでいる ようすに、先生が 気づいて「何か あった？」と 聞いてくれた。

- こまっていることを 話す → 先生：「話してくれて ありがとう。いっしょに 考えよう」
- 「だいじょうぶです」と 言う → 先生：「いつでも 話してね」と 言ってくれた。

### ゴロゴロ する

今日は 何も しないで、ゲームを したり ねころんだり。気もちは 楽だけど、やる ことは 先のばしに なった…

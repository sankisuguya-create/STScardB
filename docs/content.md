## 課題

### わからない問題（normal）

- 状きょう：算数の じゅぎょう中。黒板の 問題を 見ても、どうやって とけば いいのか わからない。まわりの 子は どんどん ノートに 書いている…
- 3つの姿：ハテナ だいまじん → むずかしそうな プリント → わからない 1問
- つぎに起きそうなこと：あせってくる／どんどん むずかしく見えてくる／まわりが すすんでいく
- 場面カード：「わからない」と言う、となりの人に 聞く、とばして 次へ
- 相手から見ると：となりの子：「聞いてくれたら、すぐ 教えたのに」

### ろうかで ぶつかられた（normal）

- 状きょう：休み時間、ろうかを 歩いていたら、うしろから ドンッと ぶつかられた。かたが いたい。「わざと？」と 思った しゅんかん、むかっと した。
- 3つの姿：ドンッと ぶつかる かいぶつ → わざと ぶつかってきた？ あの子 → よそ見して ぶつかっただけ

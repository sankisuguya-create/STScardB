## できごと

### わすれものに 気づいた朝

教室について、算数のノートを わすれたことに 気づいた。

- 先生に 正直に言う → 「言いに来てくれて ありがとう」と言われた。
- となりの子に 紙を 一まい もらう（信頼5以上） → 「いいよ」と すぐ 貸してくれた。
- だまっておく → じゅぎょう中、ずっと 気になってしまった。

### 友だちが こまっている

給食のあと、友だちが 牛にゅうを こぼして こまっている。

- 「手つだおうか？」と言う → いっしょに ふいた。「ありがとう」と言われた。
- 先生を よびに行く → 先生が ぞうきんを 持ってきてくれた。
- 見なかったことにする → そのまま 席にもどった。

### 図書室で 本を 見つけた

休み時間に 図書室へ 行ったら、気になる 本が 3さつ あった。

- 『気もちの ことば じてん』を 読む → 気もちを 言葉に すると すっきりする、と 書いてあった。
- 『べんきょうの コツ』を 読む → 時間を 決めると 集中できる、と わかった。
- 『友だちと なかよく』を 読む → 「ありがとう」の 言い方が いろいろ のっていた。

### 夕ごはんの 時間

お家の人が「今日は どうだった？」と 聞いてくれた。

- 今日 あったことを 話す → 話したら 気もちが 軽くなった。
- 「ふつう」とだけ 言う → そのまま ごはんを 食べた。

### やり直しのチャンス

この前 言い合いになった子と、ろうかで 二人きりになった。

- 「この前は ごめんね」と言う → 「ううん、こっちこそ」と言ってくれた。
- あいさつだけ する → 「おはよう」と 返ってきた。
